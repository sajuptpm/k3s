# K3s Workflow Infrastructure, Tools & Cost Estimate

## 1. Executive Summary & Methodology

This document details the exhaustive infrastructure, tooling, compute runner, and cost analysis for **K3s** across all 20 GitHub Actions pipelines located in `.github/workflows/`.

### Methodology & Scope:
- **Upstream Baseline Analysis:** Evaluates the workflows strictly based on their original upstream design and infrastructure requirements (before local fork modifications).
- **Zero Alternate Options Bias:** Reflects the actual upstream enterprise tooling (e.g., SUSE HashiCorp Vault, AWS S3, private container registries, Docker Hub organizations, multi-OS matrix runners, Codecov, and OpenSSF/Aqua security suites).
- **Dual Perspective Costing:** Captures both the upstream commercial cost basis and the open-source fork release model requirements pulled directly from `Sheet2` and `Sheet3` of `workflow-fixes/infra_tool_estimate.xlsx`.
- **Mandatory Assessment:** Evaluates whether each workflow is strictly required (`Yes`/`No`) for a forked repository producing independent open-source releases.

## 3. Breakdown by Functional Category

### 1. Build & Packaging Pipelines
- **Pipelines:** [`build-k3s.yaml`](file:///c:/projects/k3s_new/k3s/.github/workflows/build-k3s.yaml), [`airgap.yaml`](file:///c:/projects/k3s_new/k3s/.github/workflows/airgap.yaml)
- **Role:** Compiles binary executables across `amd64`, `arm64`, and `arm`, builds core container runtime images, extracts packages, and generates multi-architecture airgap archives (`.tar.zst`, `.tar.gz`) along with cryptographic SHA256 checksums.
- **Mandatory for Fork:** **Yes.** Any release from a fork must execute these pipelines to generate deployable K3s binaries and offline tarballs.
- **Infrastructure:** Standard GitHub-hosted Linux runners (`ubuntu-22.04`), QEMU multi-arch emulation, Buildx, and Go toolchain. Cost: **$0.00**.

### 2. Release & Release Documentation Pipelines
- **Pipelines:** [`release.yml`](file:///c:/projects/k3s_new/k3s/.github/workflows/release.yml)
- **Role:** Coordinates the end-to-end release lifecycle. Orchestrates builds, authenticates against secret stores, pushes container images, validates all 16 distribution assets via [`scripts/validate-artifacts`](file:///c:/projects/k3s_new/k3s/scripts/validate-artifacts), publishes GitHub Pre-Releases, and syncs tarballs to distribution buckets.
- **Mandatory for Fork:** **Yes.** Essential for producing and publishing official release tags and assets.
- **Commercial vs. Fork Infrastructure:**
  - *Upstream Enterprise:* Requires HashiCorp Vault ($6K–$30K/yr), AWS S3/CloudFront ($1.2K–$6K/yr), SUSE Prime private registries, and paid Docker Hub organization ($180/seat/yr).
