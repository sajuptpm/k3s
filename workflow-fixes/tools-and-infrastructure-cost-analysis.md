# K3s CI/CD Tools & Infrastructure Component Analysis (Before Code Change)

## Executive Summary
This document provides a comprehensive, evidence-based inventory of all tools, cloud infrastructure components, SaaS platforms, registries, compute runners, and security scanners utilized in the **k3s-io/k3s** repository across its 20 GitHub Actions workflows prior to our modernization and dual-mode refactoring.

Each item includes exact code-level evidence from the upstream workflows, subscription/billing mechanics, estimated commercial market costs, operational purposes, and an architectural analysis of the resource burden before code changes.
